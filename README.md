# Sci Life Spectrum — instaladores

Instaladores do **Sci Life Spectrum** para Windows. O app verifica esta página sozinho e se atualiza.

**Baixar:** abra a [última versão](https://github.com/LeongsGT/sci-life-spectrum-releases/releases/latest) e clique em `SciLifeSpectrum-Setup-….exe`.

O código-fonte não fica aqui; este repositório só guarda os instaladores.
